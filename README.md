# TemaSelectosIII

¡Hola! En este repositorio está contenido mi Proyecto Final para la materia Temas Selectos de Ingeniería en Computacipon III: Realidad Virtual y Realidad Aumentada. 

Más puntualmente, está contenido el APK de dicha aplicación, el código fuente y, por lo tanto, el proyecto entero para ser importado a Unity Hub (Está con la versión Unity 6) y la documentación detrás de él. 

El APK está contenido en la carpeta de nombre homónimo. La documentación se encuentra en la carpeta Docs (Análisis de costos, Análisis de viabilidad, Determinación del precio de venta de la aplicación, Manual de usuario y Manual técnico). En la carpeta Evidences se muestra un video del funcionamiento de la aplicación. 

¡Saludos!
